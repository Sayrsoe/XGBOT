# XGBOT project instructions

The owner authorizes phases separately and decides merges, publication terms and deployment. Scope XG-2A to the repository foundation, invented v0.1 evidence contract, validator, examples and local contract tests.

Run the contract suite from the repository root using the command in README.md. Keep temporary output in tasks/XG-2A/testing/ and final review evidence in tasks/XG-2A/final/. Use invented inputs for this phase. Preserve raw text, exact decimal values, field evidence and revision history across changes.

Use a feature branch and draft PR once an authorized base exists. Initial publication to remote main requires separate, explicit owner approval. Transfer of PremFootballBot components belongs to a separately approved phase.
